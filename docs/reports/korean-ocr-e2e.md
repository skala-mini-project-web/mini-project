# Korean OCR browser E2E receipt

Issue #87 is accepted only from a real local Docker stack and browser run; mock-mode results are invalid.

## Run

```bash
python3 tools/generate_synthetic_ocr_fixtures.py
python3 tools/validate_synthetic_ocr_fixtures.py
node frontend/scripts/real-korean-ocr-e2e.mjs
```

The browser script writes an immutable JSON receipt to `docs/reports/runtime/korean-ocr-e2e-<run-key>.json` (override with `KOREAN_OCR_E2E_RECEIPT`). The receipt records fixture/generator hashes, PM and reviewer identities, document/run IDs, page routes and OCR provenance, confirmation/reload assertions, and all page errors, request failures, unexpected API calls, and non-2xx API responses.

## Runtime result

- Receipt: _generated by the script_
- Outcome: _PASS or FAIL from the receipt_
- Environment: _service URLs and timestamps from the receipt_
